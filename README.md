# Pacman-Game
It's a simple pacman game.
Compile the Pacman.exe file in windows, then run the exe file and have fun.
You can play the game in three different levels: Easy, Medium, Hard. The pacman can be moved by ,`w` ,`a` ,`s` ,`d` keys.
